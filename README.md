# 🐘 Basic PHP Exercises

Welcome to my PHP learning repository! This space is dedicated to collecting practical exercises, code challenges, and language fundamentals that I develop as I progress through my training by ITAcademy

## 🚀 Development Environment
* **PHP** (Version 8.2.12)
* **Editor:** [Visual Studio Code](https://visualstudio.com)
* **Recommended Extension:** PHP Server (or whichever extension you use to run them)

## 📂 Repository Structure

The project is organized by topics for easy navigation:

* `nivel1/`: Exercises on data types, strings, and basic operations. Conditionals (if, switch, for-each)
* `nivel 2/`: Function declarations, passing parameters, and built-in PHP functions.


## 🛠️ How to Run This Project

If you want to test these exercises in your local environment using Visual Studio Code, follow these steps:

1. **Clone this repository:**
   ```bash
   git clone https://github.com
   ```

2. **Open the folder in your editor:**
   Open Visual Studio Code, go to `File -> Open Folder`, and select the cloned repository folder.

3. **Run the files:**
   * Open any `.php` file.
   * Right-click inside the editor and select "Run code"
